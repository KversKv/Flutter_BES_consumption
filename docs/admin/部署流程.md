# 部署流程（Flutter Web 静态 + chip_server 后端）

> ⚠️ 架构变更说明：admin 的 **Save / Sync Excel / Reset 需要把改动写回 JSON 源文件**，
> 而浏览器无法直接写服务器磁盘，因此**必须部署 `chip_server` 后端进程**。
> 仅托管静态 `build/web` 是不够的（admin 保存会报「后端不可达」）。
>
> 本文档已据此更新：**Nginx 托管前端静态 + 反代 `/api` 到本机 `chip_server(:8088)`**。

---

## 一、整体架构（全景图）

```text
浏览器
  │  http://172.25.10.143:5174/
  ▼
Nginx (:5174)
  ├── /        → 静态文件 /var/www/flutter_web   （Flutter build/web）
  └── /api/    → 反向代理 http://127.0.0.1:8088   （chip_server 后端）
                       │
                       ▼
              chip_server (:8088, systemd 常驻)
                       │  读/写
                       ▼
              /opt/chip_server/assets/data/chips/**.json   （admin 数据落地）
              /opt/chip_server/.chip_backups/              （写前自动备份）
```

- **前端**：Flutter Web，纯静态，由 Nginx 发。
- **后端**：`chip_server`（Dart shelf），提供 `GET/POST /api/chips`，admin 数据落地于此。
- **推荐环境**：Ubuntu 20.04 / 22.04。

---

## 二、一键部署（推荐）

本地项目根目录已提供 `update_serve.py`，自动完成「构建 → 上传前端 → 上传并编译后端 → 重启服务」：

```powershell
# 首次与日常更新都用它
python update_serve.py
```

> 一键脚本前置条件：
> 1. 本地已装 Flutter；2. 已配置 SSH 免密登录到 `mingyuanli@172.25.10.143`；
> 3. **服务器已装 Dart SDK**（后端在服务器上 `dart compile exe`）；
> 4. 服务器已按下文「三」装好并配置 Nginx（含 `/api` 反代）。
>
> 脚本参数：`--frontend-only` / `--backend-only` / `--skip-build`。

下面「三、四」是**首次手动初始化**步骤；之后日常更新见 `服务器更新流程.md`。

## 三、首次服务器初始化

### ✅ Step 1：登录服务器

```bash
ssh mingyuanli@172.25.10.143
```

### ✅ Step 2：安装 Nginx 与 Dart SDK

```bash
# Nginx
sudo apt update && sudo apt install -y nginx
sudo systemctl enable --now nginx

# Dart SDK（后端编译/运行需要）
sudo apt install -y apt-transport-https
wget -qO- https://dl-ssl.google.com/linux/linux_signing_key.pub | sudo gpg --dearmor -o /usr/share/keyrings/dart.gpg
echo 'deb [signed-by=/usr/share/keyrings/dart.gpg arch=amd64] https://storage.googleapis.com/download.dartlang.org/linux/debian stable main' | sudo tee /etc/apt/sources.list.d/dart_stable.list
sudo apt update && sudo apt install -y dart
dart --version   # 确认安装成功
```

### ✅ Step 3：创建目录并授权

```bash
# 前端静态目录（注意：scp 不会自动建目录，必须先建好）
sudo mkdir -p /var/www/flutter_web
sudo chown -R mingyuanli:mingyuanli /var/www/flutter_web

# 后端目录
sudo mkdir -p /opt/chip_server
sudo chown -R mingyuanli:mingyuanli /opt/chip_server
```

> ❗ 历史坑：曾在家目录执行 `mkdir var/www/...`，实际建到了
> `/home/mingyuanli/var/www/...` 而非 `/var/www/...`，导致 scp `path canonicalization failed`。
> **必须用 `sudo mkdir -p /var/www/flutter_web`（带前导 `/`）。**

## 四、配置 Nginx（静态 + /api 反代）

```bash
sudo nano /etc/nginx/sites-available/flutter_web
```

写入（**关键：新增 `/api/` 反代到 chip_server**）：

```nginx
server {
    listen 5174;
    server_name 172.25.10.143;   # 没域名先用 IP

    root /var/www/flutter_web;
    index index.html;

    # Flutter Web 路由（刷新不 404）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API：反代到本机 chip_server
    location /api/ {
        proxy_pass http://127.0.0.1:8088;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        # chip_server 自身已开 CORS；同源访问时这些头非必需，保留无害
    }

    # 静态资源缓存（可选）
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public";
    }

    # 字体不缓存，避免图标显示不全（历史坑）
    location /assets/fonts/ {
        add_header Cache-Control "no-store, no-cache, must-revalidate, max-age=0" always;
        expires -1;
    }
}
```

启用并校验：

```bash
sudo ln -sf /etc/nginx/sites-available/flutter_web /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
sudo ufw allow 5174/tcp     # 放行端口（云服务器还需在安全组放行）
```

> 注意：`8088` 是**内部端口**，由 Nginx 反代，**不需要**对外放行；只放行 `5174`。

## 五、部署后端（由 update_serve.py 自动完成，这里说明原理）

`update_serve.py --backend-only` 会：

1. 上传 `tool/chip_server`（pubspec + bin）与 `assets/` 到 `/opt/chip_server/`；
2. 服务器上 `dart pub get` + `dart compile exe bin/server.dart -o chip_server`；
3. 写入 systemd 服务 `/etc/systemd/system/chip_server.service`：

   ```ini
   [Unit]
   Description=BES chip_server
   After=network.target

   [Service]
   WorkingDirectory=/opt/chip_server
   Environment=CHIP_SERVER_PORT=8088
   Environment=CHIP_PROJECT_ROOT=/opt/chip_server
   ExecStart=/opt/chip_server/chip_server
   Restart=always
   User=mingyuanli

   [Install]
   WantedBy=multi-user.target
   ```

4. `systemctl enable --now chip_server` 并重启。

> `CHIP_PROJECT_ROOT=/opt/chip_server` 让后端把 chips 根定位到
> `/opt/chip_server/assets/data/chips`，即 admin Save 的落地点。

手动管理后端：

```bash
sudo systemctl status chip_server     # 查看状态
sudo journalctl -u chip_server -f      # 实时日志
sudo systemctl restart chip_server     # 重启
```

## 七、常见坑

### 1️⃣ 刷新页面 404
必须有 `try_files $uri $uri/ /index.html;`（Flutter Web 路由必需）。

### 2️⃣ admin Save 报「后端不可达」
- 检查 `chip_server` 是否在跑：`sudo systemctl status chip_server`；
- 检查 Nginx 是否配了 `/api/` 反代且 `nginx -t` 通过；
- `curl http://127.0.0.1:8088/api/chips` 在服务器本机自测后端。

### 3️⃣ scp 报 `path canonicalization failed`
远端目录不存在。scp 不会自动建目录，先 `sudo mkdir -p` 并 `chown`。

### 4️⃣ 图标/字体显示不全
旧字体缓存所致。Nginx 已对 `/assets/fonts/` 关缓存；浏览器侧用无痕窗口或
DevTools → Application → Clear site data 清理。

### 5️⃣ HTTPS（正式环境建议）
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your.domain.com
```
