## 推荐部署环境:

	👉 **强烈推荐：Linux（Ubuntu 20.04 / 22.04）**

## 二、Flutter Web 部署整体流程（全景图）

```text
VS Code 本地开发
      ↓
flutter build web
      ↓
生成 build/web
      ↓
上传到服务器
      ↓
Nginx 配置
      ↓
浏览器访问
```

## 三、详细部署步骤（Linux + Nginx，推荐）

下面以 **Ubuntu 22.04** 为例。

---

### ✅ Step 1：服务器准备

#### 1️⃣ 购买 / 准备服务器

- 系统：**Ubuntu 20.04 / 22.04**
- 配置建议：

  - 1C2G（测试 / 小项目）
  - 2C4G（正式）

#### 2️⃣ 登录服务器

```bash
ssh root@你的服务器IP
```

---

### ✅ Step 2：本地构建 Flutter Web

在你 **本地 VS Code / 命令行** 执行：

```bash
flutter config --enable-web
flutter build web --release
```

构建完成后得到：

```text
build/web/
├── index.html
├── flutter.js
├── assets/
└── main.dart.js
```

📌 **注意**：
👉 **服务器不需要安装 Flutter！** 
👉 只需要 `build/web` 里的静态文件

---

### ✅ Step 3：上传到服务器

#### 方法 1（推荐）：SCP

```bash
scp -r build/web root@服务器IP:/var/www/flutter_web
```

#### 方法 2：WinSCP / FileZilla（Windows 用户友好）

---

### ✅ Step 4：安装并配置 Nginx

#### 1️⃣ 安装 Nginx

```bash
apt update
apt install -y nginx
```

#### 2️⃣ 启动 Nginx

```bash
systemctl start nginx
systemctl enable nginx
```

访问：

```text
http://服务器IP
```

看到 Nginx 欢迎页说明成功。

---

### ✅ Step 5：配置 Flutter Web 站点

#### 1️⃣ 创建 Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/flutter_web
```

写入：

```nginx
server {
    listen 80;
    server_name your.domain.com;   # 没域名可以先用 IP

    root /var/www/flutter_web;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存（可选但推荐）
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public";
    }
}
```

```nginx

    listen 5174;
    server_name 172.25.10.143;   # 没域名可以先用 IP
```

然后执行：

```nginx
sudo nginx -t

sudo systemctl reload nginx
```

还需要确认服务器防火墙/云服务器安全组放行 5174 端口：

```nginx
sudo ufw allow 5174/tcp
```


#### 2️⃣ 启用配置

```bash
ln -s /etc/nginx/sites-available/flutter_web /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### ✅ Step 6：浏览器访问

```text
http://服务器IP
或
http://your.domain.com
```

🎉 **Flutter Web 成功上线**

## 一、为什么会报这个错？

### ❌ 报错回顾

```text
scp: realpath /var/www/flutter_web: No such file
scp: path canonicalization failed
```

### ✅ 根本原因（只有一个）

> **服务器上**  **`/var/www/flutter_web`** **这个目录当时并不存在**

`scp` **不会自动创建远端目录**，目标路径必须提前存在。

---

## 二、你现在做了什么？——关键点来了 ⚠️

你在服务器上执行的是：

```bash
mkdir var
cd var
mkdir www
cd www
mkdir flutter_web
```

📌 这一步 **创建的是：**

```text
/home/mingyuanli/var/www/flutter_web
```

❌ **而不是：**

```text
/var/www/flutter_web
```

---

## 三、路径对照（非常重要）

| 你以为的 | 实际          |
| ---------- | --------------- |
| `/var/www/flutter_web`         | ❌ 不存在     |
| `/home/mingyuanli/var/www/flutter_web`         | ✅ 你刚创建的 |

所以：

```bash
scp ... :/var/www/flutter_web
```

自然失败。

---

## 四、两种正确解决方案（推荐第 1 种）

---

## ✅ 方案 1（**强烈推荐，符合 Nginx 规范**）

### 1️⃣ 用 **root / sudo** 创建真正的目录

```bash
sudo mkdir -p /var/www/flutter_web
sudo chown -R mingyuanli:mingyuanli /var/www/flutter_web
```

解释一下：

- `/var/www` 是 **系统级 Web 根目录**
- 必须 `sudo`
- `chown` 让你普通用户可以上传文件

---

### 2️⃣ 再次上传（本地 Windows 执行）

```bash
scp -r build/web/* mingyuanli@172.25.10.143:/var/www/flutter_web/
```

📌 **注意这里我改了两个点：**

- `build/web/*`（只拷贝内容，不多套一层 web）
- 目标路径末尾 `/`
