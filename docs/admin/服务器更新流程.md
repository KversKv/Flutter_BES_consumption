## 一、最简单可靠方案（手动，但不容易出错）⭐推荐先用

### 适用场景

- 项目还在迭代
- 更新频率不高
- 不想引入 CI/CD

---

### ✅ 标准更新流程（4 步）

#### 1️⃣ 本地重新构建

```bash
flutter build web --release


flutter build web --release --no-tree-shake-icons --pwa-strategy=none
```

---

#### 2️⃣ 上传到服务器（覆盖旧版本）

> ⚠️ 关键点：**只上传 web 内容，不要多一层目录**


Linux:

```bash
sudo chown -R mingyuanli:mingyuanli /var/www/flutter_web
rm -rf /var/www/flutter_web/*
```

本地:

```bash
scp -r build/web/* mingyuanli@172.25.10.143:/var/www/flutter_web/
```

📌 `*` 很重要，否则容易多套一层目录。

---

#### 3️⃣ （可选但推荐）清理旧资源缓存

```bash
sudo find /var/www/flutter_web -name "*.map" -delete
```

---

#### 4️⃣ 直接刷新浏览器

- **不需要重启 Nginx**
- 如果有缓存：`Ctrl + F5`



#### 5.  图标显示不完全

先做一个快速判断：

```text
用无痕窗口打开 http://172.25.10.143/admin
```

如果无痕窗口正常，那就 100% 是当前浏览器缓存。

建议把 Nginx 字体缓存先关掉：

```nginx
location /assets/fonts/ {
    add_header Cache-Control "no-store, no-cache, must-revalidate, max-age=0" always;
    expires -1;
}
```

然后：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

浏览器这边再做一次彻底清理：

1. 打开 DevTools
2. Network 勾选 `Disable cache`
3. Application → Storage → `Clear site data`
4. 关闭这个页面标签，重新打开 `http://172.25.10.143/admin`

你现在服务器产物本身看起来已经是对的，卡住的是旧字体缓存。


---

### 👍 优点

- 简单
- 风险低
- 最容易排错
