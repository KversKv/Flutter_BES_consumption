## 标注体系（全项目通用）

- `[事实]` 仓库可直接验证
- `[决策]` 人为主动选择
- `[约束]` 外部或不可轻改的限制
- `[坑]` 已踩过 / 已修复
- `[待验证]` 暂定结论，等待证据
